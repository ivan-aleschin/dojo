# Компании: куда подаваться бэкендеру

Два файла:

- **[`shortlist.md`](shortlist.md)** — куда реально стоит идти и почему, с фильтром
  «переезд в Сербию через ~3 года». Основной документ.
- **[`oriocs_list.md`](oriocs_list.md)** — полный список компаний с договором о практике
  из ОРИОКС (выгружен 24.08.2026), разобранный по категориям с вердиктами.

## Главный принцип

**Бумага о практике и место реальной работы — это две разные вещи, и их не надо
связывать.** Договор с МИЭТ упрощает бумагу, но он не критерий выбора работодателя:
практику можно закрыть через кафедру или мелкую контору из списка, а работать
там, где реально учат. Жертвовать качеством опыта ради удобства документа — плохой
размен: бумага живёт год, а строчка в резюме — следующие пять лет.

## Три фильтра, через которые прогоняем любое предложение

1. **Переносимость стека.** Go / Python, PostgreSQL, Kafka, Kubernetes, highload,
   observability — это то, что читается в резюме одинаково в Москве и в Белграде.
   Стек «1С», «ПАК под реестр Минцифры», «схемотехника» — не читается.
2. **Ограничения на выезд.** Оборонка, КИИ и всё, что связано с допуском к гостайне,
   создаёт риск ограничений на выезд и проблем с визами. Для человека, который
   планирует релокацию, это дисквалифицирующий фактор, а не мелочь.
3. **Что останется через год.** Либо оффер и деньги на 2–3 года, либо навык,
   который сам себя продаёт, либо имя, которое узнают. Стажировка, где всё это
   отсутствует, — потерянные девять месяцев.
