# Паттерн 01 — Hash Map / Set

> **Приоритет: отбор.** Самый частый паттерн на онлайн-экзаменах. Если из 5 задач
> отборочного ты узнаёшь хеш-задачу за 30 секунд — уже полдела.

## Идея простыми словами

Хеш-таблица отвечает на вопрос «видел ли я это раньше?» и «сколько раз я это видел?»
за **`O(1)`**. Всё, что паттерн делает — заменяет второй вложенный цикл
(`O(n²)` — «для каждого элемента пробегу остальные») на один проход с памятью.

**Размен:** тратим `O(n)` памяти, выигрываем множитель `n` по времени.
Это первое, что нужно проговорить вслух на собесе.

Две структуры:
- `set` — только факт наличия («видел / не видел»);
- `dict` — наличие + что-то ещё (индекс, счётчик, последняя позиция).

## Триггеры — когда узнать паттерн

- «найти пару / дубликат / повтор» в **неотсортированном** массиве;
- «сколько раз встречается», «самый частый», «уникальный элемент»;
- «анаграммы», «группировка по признаку»;
- «существует ли элемент такой, что …»;
- в лоб решается двумя вложенными циклами, а `n` до 10⁵ (значит `O(n²)` не влезет).

⚠️ Антитриггер: если массив **уже отсортирован**, обычно ждут
[Two Pointers](02_two_pointers.md) с памятью `O(1)`, а не хеш.

## Скелеты кода

**1. Видели ли раньше**

```python
seen = set()
for x in nums:
    if x in seen:
        return True
    seen.add(x)
return False
```

**2. Дополнение до суммы (комплемент)** — сердце Two Sum

```python
seen = {}                       # значение -> индекс
for i, x in enumerate(nums):
    need = target - x
    if need in seen:
        return (seen[need], i)
    seen[x] = i
```

Ключевой момент: проверяем **до** того, как положили текущий элемент.
Иначе `nums = [3, 3]` при `target = 6` вернёт `(0, 0)`.

**3. Частоты**

```python
from collections import Counter
freq = Counter(nums)
freq.most_common(k)
```

**4. Группировка по ключу**

```python
from collections import defaultdict
groups = defaultdict(list)
for w in words:
    key = tuple(sorted(w))      # ключ должен быть хешируемым!
    groups[key].append(w)
return list(groups.values())
```

## Разобранный эталон: Two Sum

> Дан массив целых `nums` и число `target`. Вернуть индексы двух элементов,
> дающих в сумме `target`. Ровно одно решение, один элемент нельзя использовать дважды.

**Шаг 1. Уточняющие вопросы** (обязательно вслух):
- массив отсортирован? (нет → значит хеш, а не два указателя);
- могут быть отрицательные числа? (да → нельзя оптимизировать «отсечением»);
- гарантируется ли ровно одно решение? что вернуть, если нет?
- дубликаты возможны?

**Шаг 2. Наивно.** Два цикла, `O(n²)`, память `O(1)`. Проговорить — это база,
от которой ты улучшаешь. Никогда не начинай сразу с оптимального молча.

**Шаг 3. Идея.** Для каждого `x` нам нужен ровно один конкретный «партнёр»
`target - x`. Вопрос «встречался ли партнёр раньше» — это `set`/`dict` за `O(1)`.

**Шаг 4. Код.**

```python
def two_sum(nums: list[int], target: int) -> tuple[int, int]:
    """Индексы двух чисел с суммой target.

    Время O(n), память O(n).

    >>> two_sum([2, 7, 11, 15], 9)
    (0, 1)
    >>> two_sum([3, 2, 4], 6)
    (1, 2)
    >>> two_sum([3, 3], 6)
    (0, 1)
    """
    seen: dict[int, int] = {}
    for i, x in enumerate(nums):
        need = target - x
        if need in seen:
            return (seen[need], i)
        seen[x] = i
    raise ValueError("решения нет")
```

**Шаг 5. Проверка на edge-кейсах.** `[3, 3]` — дубликаты, работает, потому что
проверка идёт до вставки. Пустой массив — вернёт `ValueError`. Отрицательные — ок.

**Шаг 6. Сложность вслух.** «Один проход, каждая операция со словарём `O(1)`
в среднем → время `O(n)`. Храню до `n` записей → память `O(n)`. Худший случай для
хеша теоретически `O(n)` на операцию при массовых коллизиях, на практике не встречается».

## Типичные ошибки

1. **Кладут в словарь до проверки** → элемент паруется сам с собой.
2. **Список как ключ** → `TypeError: unhashable type`. Нужен `tuple(sorted(w))`.
3. **`x in list` вместо `x in set`** → снова `O(n²)`, TLE на больших тестах.
4. **Забывают, что `dict` теряет дубликаты**: `{x: i for i, x in enumerate(nums)}`
   сохранит только последний индекс каждого значения.
5. **Не отвечают на «а если памяти нет?»** — правильный ответ:
   сортировка + два указателя, `O(n log n)` время и `O(1)` память.

## Задачи (по нарастанию)

Актуальны на конец 2026: это ядро отборочных Т-Банка, Авито, МТС и разминочных
задач Яндекса. Помечено `(E)` easy / `(M)` medium.

| # | Задача | Что тренирует |
|---|---|---|
| 1 | **Two Sum** (E) | комплемент, dict значение→индекс |
| 2 | **Contains Duplicate** (E) | `set`, `len(set(a)) != len(a)` |
| 3 | **Valid Anagram** (E) | `Counter` равенство |
| 4 | **Single Number** (E) | хеш ИЛИ xor — знать оба решения |
| 5 | **Intersection of Two Arrays** (E) | операции над множествами |
| 6 | **Group Anagrams** (M) | `defaultdict(list)`, ключ-кортеж |
| 7 | **Top K Frequent Elements** (M) | `Counter.most_common`, потом [через кучу](10_heap_topk.md) |
| 8 | **Longest Consecutive Sequence** (M) | set + амортизированный анализ |
| 9 | **Isomorphic Strings** (E/M) | два словаря-биекции |
| 10 | **Subarray Sum Equals K** (M) | хеш + [префиксные суммы](06_prefix_sums.md) |

**Разбор №8 (частый вопрос на секции).** Наивно — отсортировать, `O(n log n)`.
Через `set`: цепочку начинаем считать только с числа `x`, у которого нет `x-1`
в множестве. Тогда каждая цепочка проходится ровно раз → `O(n)`.

**Разбор №9.** Изоморфность требует **двух** отображений: `s→t` и `t→s`.
С одним словарём `"badc"` и `"baba"` ошибочно пройдут.
