# Паттерн 03 — Sliding Window (скользящее окно)

> **Приоритет: отбор.** Самый «доходный» паттерн: одна идея закрывает
> десяток задач про подстроки и подмассивы.

## Идея простыми словами

Задачи вида «найди лучший **непрерывный** отрезок» в лоб решаются перебором
всех отрезков — `O(n²)` или `O(n³)`. Окно превращает это в `O(n)`:
мы не пересчитываем отрезок заново, а **чиним** его — добавляем элемент справа,
убираем слева, поддерживая нужную характеристику (сумму, счётчик, максимум).

Ключевое: **каждый элемент входит в окно один раз и выходит один раз** →
суммарно `2n` операций → `O(n)`, хотя внутри цикла стоит `while`.

## Два вида окна

**1. Фиксированное `k`** — «максимальная сумма подмассива длины k».
Правая граница идёт по циклу, левая всегда `right - k + 1`.

**2. Переменное** — «самый длинный/короткий отрезок, удовлетворяющий условию».
Расширяем справа, пока можем; когда условие нарушено — сжимаем слева.

## Триггеры

- в условии есть слово **«подмассив»** / **«подстрока»** (то есть **непрерывный** кусок);
- «самый длинный / самый короткий / максимальная сумма» + ограничение;
- «не более K различных символов», «не более K замен», «без повторов»;
- «ровно k подряд идущих».

⚠️ Антитриггер: «подпоследовательность» (subsequence — можно с пропусками) —
это **не** окно, это [DP](11_backtracking_dp.md).

## Скелеты кода

**Фиксированное окно**

```python
window_sum = sum(nums[:k])
best = window_sum
for right in range(k, len(nums)):
    window_sum += nums[right] - nums[right - k]   # добавили справа, убрали слева
    best = max(best, window_sum)
return best
```

**Переменное окно — «самый длинный подходящий»**

```python
left = 0
best = 0
state = ...                       # Counter / сумма / множество
for right, x in enumerate(nums):
    add(state, x)                 # расширяем справа
    while not ok(state):          # пока нарушено — сжимаем слева
        remove(state, nums[left])
        left += 1
    best = max(best, right - left + 1)
return best
```

**Переменное окно — «самый короткий подходящий»**

```python
left = 0
best = float('inf')
total = 0
for right, x in enumerate(nums):
    total += x
    while total >= target:                 # условие ВЫПОЛНЕНО — пробуем ужать
        best = min(best, right - left + 1)
        total -= nums[left]
        left += 1
return 0 if best == float('inf') else best
```

Разница принципиальная: в «длинном» `while` чинит **нарушение**,
в «коротком» `while` **улучшает** уже подходящий ответ. Перепутать — самая
частая ошибка в этом паттерне.

## Разобранный эталон: Longest Substring Without Repeating Characters

> Дана строка `s`. Найти длину самой длинной подстроки без повторяющихся символов.

**Уточнения:** алфавит (только латиница? юникод?), регистр важен, пустая строка → 0.

**Наивно:** все подстроки, для каждой проверка на уникальность → `O(n³)` (или `O(n²)` с set).

**Идея.** Держим окно, в котором **все символы различны**. Идём правой границей.
Если новый символ уже в окне — двигаем левую границу вправо, выкидывая символы,
пока дубликат не уйдёт. Ответ — максимальная длина окна за всё время.

```python
def length_of_longest_substring(s: str) -> int:
    """Длина самой длинной подстроки без повторов.

    Время O(n), память O(min(n, размер алфавита)).

    >>> length_of_longest_substring("abcabcbb")
    3
    >>> length_of_longest_substring("bbbbb")
    1
    >>> length_of_longest_substring("pwwkew")
    3
    >>> length_of_longest_substring("")
    0
    """
    window: set[str] = set()
    left = 0
    best = 0
    for right, c in enumerate(s):
        while c in window:
            window.remove(s[left])
            left += 1
        window.add(c)
        best = max(best, right - left + 1)
    return best
```

**Почему это `O(n)`, хотя есть вложенный `while`:** `left` только растёт и никогда
не превышает `n`. Значит внутренний цикл суммарно выполнится не больше `n` раз.
Это ровно тот аргумент, который надо произнести на собесе.

**Оптимизация (спросят как «а можно быстрее?»):** хранить `dict` символ→последний
индекс и прыгать `left = max(left, last[c] + 1)` — один проход без внутреннего цикла.

## Разобранный приём: окно с Counter

Задачи «не более K различных» / «с заменами» требуют хранить не множество, а частоты:

```python
from collections import Counter

def longest_k_distinct(s: str, k: int) -> int:
    count: Counter[str] = Counter()
    left = 0
    best = 0
    for right, c in enumerate(s):
        count[c] += 1
        while len(count) > k:            # различных стало больше k
            count[s[left]] -= 1
            if count[s[left]] == 0:
                del count[s[left]]       # ВАЖНО: удалить, иначе len врёт
            left += 1
        best = max(best, right - left + 1)
    return best
```

Забыть `del` при нуле — ошибка №1 в этом приёме: `len(count)` перестаёт означать
«количество различных символов в окне».

## Типичные ошибки

1. **Перепутаны «длинное» и «короткое» окно** — `while` не в том месте.
2. **Длина окна посчитана как `right - left`** вместо `right - left + 1`.
3. **Не удалён ключ с нулевым счётчиком** из `Counter`.
4. **Обновление ответа не в том месте**: для «длинного» — после починки окна,
   для «короткого» — внутри `while`.
5. **Применили окно к массиву с отрицательными числами** в задаче на сумму.
   Окно требует монотонности: добавил элемент → сумма выросла. С отрицательными
   это ломается, и нужны [префиксные суммы + хеш](06_prefix_sums.md).
   **Это самый глубокий вопрос по паттерну — знать ответ обязательно.**
6. **Забыли начальный случай** для фиксированного окна (`len(nums) < k`).
