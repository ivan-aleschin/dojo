# Паттерн 05 — Stack / Monotonic Stack

> **Приоритет: отбор.** Скобки и «следующий больший» — две задачи,
> которые встречаются почти в каждом наборе.

## Идея простыми словами

Стек — «последним пришёл, первым вышел». В Python это обычный список:
`append` кладёт, `pop()` снимает, оба `O(1)`.

Паттерн нужен, когда обработку элемента приходится **отложить** до тех пор,
пока не встретится парный/подходящий элемент дальше по массиву.

Два подпаттерна:
**1. Стек соответствий** — скобки, вложенность, вычисление выражений, отмена операций.
**2. Монотонный стек** — «ближайший больший/меньший элемент» за `O(n)` вместо `O(n²)`.

## Триггеры

- скобки, вложенность, парность, «корректная последовательность»;
- «отменить последнее действие», «упростить путь», обратная польская запись;
- **«следующий больший элемент»**, «сколько дней до потепления», «наибольший прямоугольник»;
- обход дерева без рекурсии;
- в условии есть «удалить так, чтобы результат был минимальным/максимальным».

## Скелет №1: стек соответствий

```python
def is_valid(s: str) -> bool:
    pairs = {")": "(", "]": "[", "}": "{"}
    stack: list[str] = []
    for c in s:
        if c in pairs.values():
            stack.append(c)
        elif c in pairs:
            if not stack or stack.pop() != pairs[c]:
                return False
    return not stack        # ВАЖНО: остаток в стеке = незакрытые скобки
```

Два места, где заваливают: `not stack` перед `pop()` (иначе `IndexError` на `")("`)
и финальная проверка пустоты (иначе `"(("` пройдёт как валидная).

## Скелет №2: монотонный стек

Держим стек **индексов**, значения в котором монотонны (убывают или возрастают).
Пришёл новый элемент, который нарушает монотонность → снимаем со стека всех,
для кого этот новый элемент и есть ответ.

```python
def daily_temperatures(temps: list[int]) -> list[int]:
    """Через сколько дней станет теплее.

    Монотонно убывающий стек индексов. Время O(n), память O(n).

    >>> daily_temperatures([73, 74, 75, 71, 69, 72, 76, 73])
    [1, 1, 4, 2, 1, 1, 0, 0]
    >>> daily_temperatures([30, 40, 50, 60])
    [1, 1, 1, 0]
    >>> daily_temperatures([30, 20, 10])
    [0, 0, 0]
    """
    ans = [0] * len(temps)
    stack: list[int] = []                    # индексы, температуры убывают
    for i, t in enumerate(temps):
        while stack and temps[stack[-1]] < t:
            j = stack.pop()
            ans[j] = i - j                   # нашли ответ для дня j
        stack.append(i)
    return ans
```

**Почему `O(n)`, а не `O(n²)`:** каждый индекс кладётся в стек ровно раз
и снимается не больше раза → суммарно `2n` операций. Обязательно проговорить.

Как выбрать направление монотонности:

| Нужно | Стек | Снимаем, пока |
|---|---|---|
| следующий **больший** | убывающий | вершина < новый |
| следующий **меньший** | возрастающий | вершина > новый |
| предыдущий больший | убывающий, ответ берём до вставки | — |

## Разобранный эталон: Evaluate Reverse Polish Notation

> Вычислить выражение в обратной польской записи: `["2","1","+","3","*"]` → `9`.

**Идея.** Числа кладём в стек. Оператор снимает **два** последних, применяет,
кладёт результат. В конце в стеке ровно одно значение — ответ.

**Тонкость,** на которой ловят: порядок операндов. Снимается сначала **правый**:

```python
def eval_rpn(tokens: list[str]) -> int:
    """Вычисление выражения в обратной польской записи.

    Время O(n), память O(n).

    >>> eval_rpn(["2", "1", "+", "3", "*"])
    9
    >>> eval_rpn(["4", "13", "5", "/", "+"])
    6
    >>> eval_rpn(["10", "6", "9", "3", "+", "-11", "*", "/", "*", "17", "+", "5", "+"])
    22
    """
    stack: list[int] = []
    for token in tokens:
        if token in {"+", "-", "*", "/"}:
            b = stack.pop()          # СНАЧАЛА правый операнд
            a = stack.pop()
            if token == "+":
                stack.append(a + b)
            elif token == "-":
                stack.append(a - b)
            elif token == "*":
                stack.append(a * b)
            else:
                stack.append(int(a / b))   # деление К НУЛЮ, не a // b
        else:
            stack.append(int(token))
    return stack[-1]
```

Второй капкан: `-7 // 2 == -4`, а условие задачи требует усечение к нулю → `-3`.
Поэтому `int(a / b)`. Такие детали — то, что отличает «решил» от «решил правильно».

## Стек вместо рекурсии

Обход дерева в глубину без рекурсии (полезно, когда боишься `RecursionError`):

```python
stack = [root]
while stack:
    node = stack.pop()
    if not node:
        continue
    visit(node)
    stack.append(node.right)
    stack.append(node.left)     # левый кладём последним → снимется первым
```

Inorder-обход итеративно — частый вопрос на секции:

```python
stack, cur, out = [], root, []
while stack or cur:
    while cur:
        stack.append(cur)
        cur = cur.left
    cur = stack.pop()
    out.append(cur.val)
    cur = cur.right
```

## Типичные ошибки

1. **`pop()` из пустого стека** — всегда `if stack and ...`.
2. **Забыта финальная проверка** `return not stack`.
3. **Перепутан порядок операндов** при вычислении выражений.
4. **В монотонный стек кладут значения, а нужны индексы** — тогда не посчитать расстояние.
5. **Неправильное направление монотонности** → ответ «предыдущий» вместо «следующий».
6. **Не объяснили амортизацию** — интервьюер видит `while` внутри `for`
   и ждёт, что ты сам скажешь, почему это всё равно `O(n)`.
