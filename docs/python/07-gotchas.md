## 1. Мутабельный аргумент по умолчанию

```python
def add(x, acc=[]):     # ПЛОХО
    acc.append(x)
    return acc

add(1)   # [1]
add(2)   # [1, 2]  ← тот же список!
```

Значение по умолчанию вычисляется **один раз** при определении функции.
Правильно:

```python
def add(x, acc=None):
    if acc is None:
        acc = []
    acc.append(x)
    return acc
```

## 2. Копия против ссылки

```python
a = [1, 2, 3]
b = a          # ЭТО НЕ КОПИЯ — та же самая память
b.append(4)
a              # [1, 2, 3, 4]

b = a[:]       # копия (поверхностная)
b = list(a)    # то же
```

Поверхностная копия матрицы ломается:

```python
grid = [[0, 0], [0, 0]]
copy = grid[:]         # внешний список новый, ВНУТРЕННИЕ — те же
copy[0][0] = 1
grid[0][0]             # 1 — испортили оригинал

import copy as copy_mod
deep = copy_mod.deepcopy(grid)     # честная копия
# или: [row[:] for row in grid]
```

Особенно важно в backtracking: `result.append(path)` кладёт **ссылку**, и после
`path.pop()` в ответе окажется мусор. Правильно — `result.append(path[:])`.

## 3. `[[0] * m] * n`

```python
grid = [[0] * 3] * 2
grid[0][0] = 1
grid            # [[1, 0, 0], [1, 0, 0]]  ← обе строки одна и та же
```

Всегда: `[[0] * m for _ in range(n)]`.

## 4. `is` против `==`

`==` сравнивает значения, `is` — тождество объектов.

```python
a = [1, 2]
b = [1, 2]
a == b   # True
a is b   # False
```

`is` используется **только** с `None`, `True`, `False`:
`if x is None:`. Для чисел и строк `is` иногда «случайно работает»
из-за кеширования мелких значений — на это нельзя опираться.

## 5. Изменение коллекции во время итерации

```python
for x in nums:
    if x < 0:
        nums.remove(x)      # пропустит элементы, поведение непредсказуемо
```

Правильно — создать новый список: `nums = [x for x in nums if x >= 0]`.
То же для словаря: `for k in list(d):` если внутри удаляешь ключи.

## 6. `sort()` против `sorted()`

```python
a.sort()          # НА МЕСТЕ, возвращает None
b = a.sort()      # b == None ← частая ошибка
b = sorted(a)     # новый список
```

То же с `reverse()` / `reversed()`, `append` (возвращает `None`).

## 7. Целочисленное деление и округление

```python
5 / 2      # 2.5  float — и точность плывёт на больших числах
5 // 2     # 2
-5 // 2    # -3, а не -2
round(0.5) # 0, round(1.5) # 2  — банковское округление
int(-2.7)  # -2 (обрезание к нулю), а -2.7 // 1 == -3.0
```

Индексы и середину массива считать **только** через `//`.

## 8. Сравнение float

```python
0.1 + 0.2 == 0.3      # False
abs(0.1 + 0.2 - 0.3) < 1e-9   # так правильно
```

В задачах на геометрию / бинпоиск по вещественному ответу — только через epsilon.

## 9. `in` по списку — это `O(n)`

```python
for x in a:
    if x in b:       # b — список → O(n²) суммарно
        ...
bs = set(b)          # O(n) один раз
for x in a:
    if x in bs:      # O(1)
```

Самая частая причина TLE у начинающих.

## 10. Строки неизменяемы, склейка в цикле — `O(n²)`

```python
res = ""
for c in chars:
    res += c        # каждая склейка копирует всю строку
res = "".join(chars)  # правильно
```

## 11. Переменная цикла живёт после цикла

```python
for i in range(3):
    pass
print(i)     # 2 — не ошибка, но источник багов при вложенных циклах
```

Ещё коварнее: если `range` пустой, `i` вообще не определена → `NameError`.

## 12. `dict` как счётчик без `get`

```python
d = {}
d["a"] += 1        # KeyError
d["a"] = d.get("a", 0) + 1    # или defaultdict(int) / Counter
```

## 14. `range` не список

```python
r = range(5)
r[2]        # 3 — индексация работает
r.append(6) # AttributeError — это не список
list(r)     # [0, 1, 2, 3, 4]
```
