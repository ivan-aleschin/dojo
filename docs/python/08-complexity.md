# Python 08 — Сложность: как считать и как говорить вслух

> 15 минут. На собесе оценку сложности спрашивают **всегда**. Молчание = минус балл.

## Что такое O(...) в двух предложениях

`O(f(n))` — как растёт время работы при росте размера входа `n`.
Константы и младшие слагаемые выкидываются: `3n² + 100n + 7` → `O(n²)`.

## Шкала, которую надо помнить

| Сложность | Название | n, влезающее в 1 секунду |
|---|---|---|
| `O(1)` | константа | любое |
| `O(log n)` | логарифм | ~10¹⁸ |
| `O(n)` | линейная | ~10⁷ (Python) |
| `O(n log n)` | сортировка | ~10⁶ |
| `O(n²)` | квадрат | ~3000 |
| `O(2ⁿ)` | экспонента | ~20–25 |
| `O(n!)` | факториал | ~10 |

**Как читать ограничения задачи** — это подсказка, какой алгоритм от тебя ждут:

| В условии | Скорее всего нужен |
|---|---|
| `n ≤ 10` | перебор, backtracking, `O(n!)` / `O(2ⁿ)` |
| `n ≤ 20` | битовые маски, `O(2ⁿ)` |
| `n ≤ 500` | `O(n³)`, 2D-динамика |
| `n ≤ 5000` | `O(n²)` |
| `n ≤ 10⁵` | `O(n log n)` — сортировка, бинпоиск, куча |
| `n ≤ 10⁶` и больше | `O(n)` или `O(log n)`, только один проход |

Python медленнее C++ примерно в 30–50 раз. Если в условии `n = 10⁶`
и задумано `O(n log n)`, на Python это может не влезть — тогда нужны
встроенные функции (`sort`, `sum`, `Counter`), которые написаны на C.

## Как считать: три правила

1. **Последовательные блоки складываются**, берём максимум:
   `O(n) + O(n log n)` → `O(n log n)`.
2. **Вложенные циклы умножаются**: цикл по `n` внутри цикла по `m` → `O(n·m)`.
3. **Скрытые операции считаются**: `x in list` — `O(n)`, `list.pop(0)` — `O(n)`,
   срез `a[i:j]` — `O(j-i)`, `sorted` — `O(n log n)`.

Пример разбора:

```python
def f(nums):
    s = set(nums)                 # O(n)
    best = 0
    for x in nums:                # n раз
        if x - 1 not in s:        # O(1)
            y = x
            while y + 1 in s:     # суммарно по ВСЕМ x — O(n), не O(n²)
                y += 1
            best = max(best, y - x + 1)
    return best
```

Итого `O(n)` время, `O(n)` память. Внутренний `while` выглядит как второй цикл,
но каждая цепочка проходится ровно один раз — это **амортизированный** анализ,
и именно его хотят услышать на собесе (это Longest Consecutive Sequence).

## Стоимость операций Python

| Операция | Время |
|---|---|
| `list[i]`, `len`, `append`, `pop()` | `O(1)` |
| `list.pop(0)`, `insert(0, x)`, `remove(x)`, `x in list` | `O(n)` |
| `dict[k]`, `k in dict`, `set.add`, `x in set` | `O(1)` в среднем |
| `sorted(a)`, `a.sort()` | `O(n log n)` |
| `heappush`, `heappop` | `O(log n)` |
| `heapify` | `O(n)` |
| `bisect_left/right` | `O(log n)` |
| `deque.appendleft/popleft` | `O(1)` |
| срез `a[i:j]` | `O(j - i)` |
| `"".join(parts)` | `O(суммарной длины)` |
| `s1 + s2` (строки) | `O(len(s1) + len(s2))` |

## Память

Считается **дополнительная** память, не считая входа. Отвечать надо про обе:
«время `O(n log n)`, память `O(1)`, если сортируем на месте».

Не забывай про **стек рекурсии**: рекурсивный обход дерева — это `O(h)` памяти,
где `h` — высота; в худшем случае (вырожденное дерево) `O(n)`.

## Как это звучит на собеседовании

Плохо: «ну, тут два цикла».

Хорошо:

> «Внешний цикл идёт по n элементам, внутри — операция поиска в множестве за O(1)
> в среднем, значит время O(n). Дополнительно храню множество из n элементов —
> память O(n). Можно уменьшить память до O(1), если разрешено сортировать вход,
> но тогда время станет O(n log n). Что важнее в вашем случае?»

Последний вопрос — про размен времени и памяти — сильный ход: показывает,
что ты думаешь про требования, а не только про код.

## Мини-задачи: назови сложность вслух

```python
1) for i in range(n):
       for j in range(i, n): ...
2) while n > 0: n //= 2
3) for x in a:
       if x in b:            # b — список длины m
4) sorted(nums)[k]
5) def f(n):
       if n < 2: return n
       return f(n-1) + f(n-2)
6) def g(node):
       if not node: return 0
       return 1 + max(g(node.left), g(node.right))
```

<details><summary>Ответы</summary>

1. `O(n²)` — сумма 1+2+…+n = n(n+1)/2.
2. `O(log n)`.
3. `O(n·m)`; с `set(b)` — `O(n + m)`.
4. `O(n log n)` время, `O(n)` память; через `heapq.nlargest` — `O(n log k)`.
5. `O(2ⁿ)` без мемоизации, `O(n)` с `@lru_cache`.
6. `O(n)` время (каждый узел раз), `O(h)` память на стеке рекурсии.
</details>
