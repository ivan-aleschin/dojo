# Python 02 — Коллекции: list, dict, set, tuple

> 25 минут. Это 80% инструментария алгоритмиста.

## Что выбрать: таблица решений

| Нужно | Структура | Доступ | Вставка |
|---|---|---|---|
| Упорядоченная последовательность, доступ по индексу | `list` | `O(1)` | в конец `O(1)`, в середину `O(n)` |
| «Видели ли мы X?» | `set` | `O(1)` | `O(1)` |
| «X → значение» | `dict` | `O(1)` | `O(1)` |
| Неизменяемый кортеж, ключ словаря | `tuple` | `O(1)` | — |
| Очередь: добавляем/снимаем с обоих концов | `deque` | `O(1)` с концов | `O(1)` |

**Главное правило собеса:** увидел «проверить наличие» в цикле по списку —
`if x in lst` это `O(n)`, и общее решение становится `O(n²)`. Замена на `set` даёт `O(n)`.

## list

```python
a = [3, 1, 2]
a.append(4)        # O(1) в конец
a.pop()            # O(1) снять с конца → 4
a.pop(0)           # O(n)! сдвигает весь список. Для очереди — deque
a.insert(0, 9)     # O(n)
a.remove(1)        # O(n), удаляет первое вхождение по значению
a.sort()           # на месте, O(n log n)
b = sorted(a)      # новый список
a.reverse()        # на месте
len(a); sum(a); min(a); max(a)
a.count(3)         # сколько раз встречается, O(n)
a.index(3)         # индекс первого вхождения, O(n), ValueError если нет
```

Создание:

```python
zeros = [0] * n                 # список из n нулей
grid = [[0] * m for _ in range(n)]   # матрица n × m
```

> 🔥 **Классическая ловушка:** `grid = [[0] * m] * n` создаёт n ссылок на ОДИН
> и тот же список. `grid[0][0] = 1` изменит все строки. Всегда через comprehension.

Стек — это просто список: `push = append`, `pop = pop()`. Оба `O(1)`.

## dict

```python
d = {}
d["a"] = 1
d["a"] += 1                # KeyError если ключа нет — сначала завести
d.get("b", 0)              # 0 вместо KeyError
d["b"] = d.get("b", 0) + 1 # идиома «счётчик» без импортов
"a" in d                   # O(1)
d.pop("a", None)           # удалить, не падая
len(d)

for k in d: ...            # по ключам
for k, v in d.items(): ... # по парам
for v in d.values(): ...
```

Словари сохраняют **порядок вставки** (гарантия языка с 3.7).

Ключом может быть только неизменяемое: число, строка, кортеж.
`d[(1, 2)] = "точка"` — можно. `d[[1, 2]]` — `TypeError`.

Сортировка словаря по значению:

```python
top = sorted(d.items(), key=lambda kv: kv[1], reverse=True)
```

## set

```python
s = set()          # ВАЖНО: {} — это пустой словарь, не множество
s = {1, 2, 3}
s.add(4)
s.discard(9)       # не падает, если нет; s.remove(9) — падает
3 in s             # O(1)

a, b = {1,2,3}, {2,3,4}
a & b   # {2, 3}     пересечение
a | b   # {1,2,3,4}  объединение
a - b   # {1}        разность
a ^ b   # {1, 4}     симметричная разность
```

Убрать дубликаты сохранив порядок: `list(dict.fromkeys(a))`.

## tuple

Неизменяемый список. Нужен как ключ словаря, элемент множества и для возврата
нескольких значений.

```python
p = (3, 4)
x, y = p           # распаковка
seen = {(0, 0), (1, 2)}   # множество координат — так помечают посещённые клетки
```

Кортежи сравниваются **лексикографически** — сначала по первому элементу:
`(1, 5) < (2, 0)` → `True`. Отсюда трюк с кучей: кладём `(приоритет, значение)`.

## Comprehensions

```python
[x * x for x in range(5)]              # [0, 1, 4, 9, 16]
[x for x in nums if x > 0]             # фильтр
{x: x * x for x in range(3)}           # {0: 0, 1: 1, 2: 4}
{c for c in "hello"}                   # {'h','e','l','o'}
[[0] * m for _ in range(n)]            # матрица
[c for row in grid for c in row]       # разложить матрицу в один список
```

Читается сверху вниз как обычный цикл: `for` слева направо, выражение — впереди.

Генераторное выражение (без квадратных скобок) не создаёт список — экономит память:

```python
sum(x * x for x in range(10 ** 6))
any(x < 0 for x in nums)
all(a[i] <= a[i + 1] for i in range(len(a) - 1))   # проверка «отсортирован ли»
```

## Мини-задачи

1. Из `[1,2,2,3,3,3]` получить словарь частот, не используя `Counter`.
2. Проверить за `O(n)`, есть ли в списке дубликаты.
3. Создать матрицу 3×4 из нулей и поставить `grid[1][2] = 5`, проверить, что
   остальные строки не изменились.
4. Найти все числа, которые есть в `a`, но нет в `b`, — одной строкой.
5. Отсортировать `words = ["bb","a","ccc"]` по длине, при равной длине — по алфавиту.

<details><summary>Ответы</summary>

```python
1) freq = {}
   for x in a:
       freq[x] = freq.get(x, 0) + 1
2) len(set(a)) != len(a)
3) grid = [[0] * 4 for _ in range(3)]
4) set(a) - set(b)
5) sorted(words, key=lambda w: (len(w), w))
```
