## Числа

```python
7 / 2      # 3.5   — ВСЕГДА float, даже 4 / 2 == 2.0
7 // 2     # 3     — целочисленное деление, округляет ВНИЗ
-7 // 2    # -4    ← вот здесь ловят на собесе, не -3
7 % 2      # 1
-7 % 2     # 1     — остаток в Python всегда со знаком делителя (не как в C)
2 ** 10    # 1024
divmod(7, 2)  # (3, 1)
```

Целые числа **безразмерные** — переполнения не бывает. `2 ** 200` посчитается точно.
Это преимущество Python на собесе: не надо думать про `int64 overflow`.

Середина отрезка при бинпоиске: `mid = (lo + hi) // 2` — безопасно, переполнения нет.

```python
abs(-5)          # 5
min(3, 1, 2)     # 1
max([3, 1, 2])   # 3
round(2.5)       # 2  ← банковское округление! round(3.5) == 4
float('inf'), float('-inf')   # бесконечности, удобны как начальное значение
```

Идиома «ищем минимум»:

```python
best = float('inf')
for x in nums:
    best = min(best, x)
```

## Строки

Строка **неизменяема**. `s[0] = 'a'` — ошибка. Любое «изменение» создаёт новую строку.

```python
s = "Hello World"
len(s)            # 11
s[0], s[-1]       # ('H', 'd')
s.lower()         # 'hello world'
s.upper()
s.strip()         # убрать пробелы по краям
s.split()         # ['Hello', 'World']  — по любым пробелам
"a,b,c".split(",")# ['a', 'b', 'c']
",".join(["a","b"])  # 'a,b'
s.replace("l", "L")
s.startswith("He"), s.endswith("ld")
s.find("World")   # 6, или -1 если нет
"World" in s      # True
```

Проверки символов — постоянно нужны в задачах на строки:

```python
c = "a"
c.isalpha()   # буква
c.isdigit()   # цифра
c.isalnum()   # буква или цифра
c.isspace()   # пробельный
ord("a"), chr(97)   # 97, 'a'  — код символа и обратно
ord("c") - ord("a") # 2 — индекс буквы в алфавите, классика для массива на 26 ячеек
```

**Важно про производительность.** Склейка в цикле — `O(n²)`:

```python
# ПЛОХО
res = ""
for c in chars:
    res += c

# ХОРОШО — собрать в список, склеить один раз, O(n)
parts = []
for c in chars:
    parts.append(c)
res = "".join(parts)
```

f-строки:

```python
n, name = 5, "Иван"
print(f"{name}: {n}")          # Иван: 5
print(f"{n * 2 = }")           # n * 2 = 10  — удобно для отладки
print(f"{3.14159:.2f}")        # 3.14
```

## Срезы — главный инструмент

`s[start:stop:step]` — `start` включается, `stop` **не** включается.

```python
a = [0, 1, 2, 3, 4, 5]
a[1:4]     # [1, 2, 3]
a[:3]      # [0, 1, 2]      с начала
a[3:]      # [3, 4, 5]      до конца
a[-2:]     # [4, 5]         последние два
a[:-1]     # [0, 1, 2, 3, 4]  всё кроме последнего
a[::2]     # [0, 2, 4]      каждый второй
a[::-1]    # [5, 4, 3, 2, 1, 0]  разворот
a[:]       # копия списка (поверхностная)
```

Срез **никогда не падает** по выходу за границы — просто отдаёт что есть:

```python
a[10:20]   # []   — не IndexError
```

А вот индекс падает: `a[10]` → `IndexError`.

Разворот строки: `s[::-1]`. Палиндром одной строкой: `s == s[::-1]`.

> ⚠️ Срез **копирует** — `O(k)` времени и памяти. В цикле по всем подстрокам
> `s[i:j]` легко превращает решение в `O(n³)`. На собесе про это спрашивают.
